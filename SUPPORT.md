# Customer Support

For help with FFmpeg Media Toolkit, open a
[GitHub issue](https://github.com/cecil-ia-labs/ffmpeg-dev/issues/new).

Include the toolkit version, operating system, command used, and relevant error
output. Remove passwords, API keys, personal data, and sensitive media before
submitting a request.

Support is provided on a best-effort basis and does not include a guaranteed
response time.
