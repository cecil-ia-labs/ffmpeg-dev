02 / OUTPUT

Generate. Copy. Run.

Export shell commands for the local FFmpeg installation or a YAML file for the toolkit's supported single-input pipeline schema.

The toolkit pipeline format currently supports sequential domain steps, not arbitrary multitrack compositions. Unsupported projects are exported as native FFmpeg commands.

Two environments.

01

Load locally

Use the File API to open media for playback, metadata inspection and waveform extraction. Nothing leaves the tab.

02

Edit visually

Organize clips, set trim ranges, choose resolution and frame rate, or add an independent audio track.

03

Render on your host

Copy the generated command, run it in a directory containing the source files, and validate the resulting media locally.

04 / OPEN SOURCE TOOLKIT

Beyond the
showroom.

The full TypeScript toolkit includes a CLI, FFprobe diagnostics, hardware capability checks, compositing, streaming, transformations, reusable pipelines and agent skills. Its local execution path validates artifacts rather than claiming success from a dry-run.

This site is a client-only composer and is not equivalent to the complete toolkit runtime.
