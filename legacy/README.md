# Legacy Bash Corpus

These scripts are preserved **unchanged** from the files supplied for the project and exist only as migration/reference material.

They are not the new implementation and should not be called by the TypeScript runtime.

Important:

- several scripts contain hard-coded paths;
- several use `eval` or POSIX-specific utilities;
- some filenames do not match actual behavior;
- some media/container semantics need correction;
- `stack_vertical.sh` contains an MIT-licensed third-party copyright notice that must be preserved if code is ported.

See `../docs/milestone-0/legacy-script-catalog.md` for the migration mapping.
